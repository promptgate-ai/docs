## 0.6.0 - 2026-10-21

The web UI release: everything the YAML and the CLI do, in a browser,
built into the binary. It runs on its own port, localhost only, with
sign-in; every change it makes is written back to the YAML — checked
like `promptgate validate`, refused when the file changed meanwhile,
backed up, written atomically and reloaded once — so the files stay the
source of truth and hand edits and UI edits mix. No Node, no CDN, no
new dependency.

### Added

- **Web UI** — served on `ui.listen` (default `127.0.0.1:7879`), or on
  the gateway's port under `ui.mount`; `ui.enabled: false`,
  `PROMPTGATE_UI_LISTEN=off` or `start --ui off` turn it off. Pages,
  styles, scripts, icons and fonts are embedded; a strict
  Content-Security-Policy allows nothing else. Light and dark theme.
  See `docs/ui.md` and `docs/ui-pages.md`.
- **Sign-in** — users live in the request log's database, passwords as
  PBKDF2-SHA256 from Go's standard library. The first start creates
  `admin` with a random password, shown once and kept in
  `ui-initial-password` until admin picks their own. Sessions store only
  a hash of their token (`ui.session_ttl`, a week at most,
  `ui.secure_cookies`); every form needs the session's CSRF token and
  cross-site posts are refused; failed sign-ins are throttled per name
  and address; everything is audited. `promptgate ui users` and
  `ui passwd` manage users from the shell. With `logging.store: off` the
  UI stays off.
- **Dashboard** — today's requests, errors, latency and spend against
  yesterday, requests per hour and spend per day as server-drawn SVG
  charts, the busiest models and keys, the budgets nearest their limit,
  endpoint anomalies; refreshing itself while visible.
- **Logs** — filtered by time, status, model, provider, key, end user,
  endpoint and session; a live view over server-sent events that reads
  the log, never the request path, and jumps to the newest rows when
  more arrive than anyone can read; each request's details and bodies.
- **Cost** — spend over 7, 30 or 90 days or by month against the period
  before, per day and per model, provider, key, endpoint or end user,
  unpriced requests pointed out, every budget's use; CSV export.
- **Endpoints** — list with today's numbers, a prompt preview from
  sample values, versions with diff and restore, evals from
  `evals/<endpoint>.yaml`, and a form to create and edit them that
  writes only what changed.
- **Playground and replay** — run an endpoint, a model or a raw request
  — also a logged one — through the running gateway as the key
  `ui:<user>`: same guardrails, limits and budgets, logged and charged;
  the answer streams in with tokens, cost, route, cache and findings.
- **Keys** — create (shown once), restrict, rotate, disable, delete;
  last use and today's traffic.
- **Policies** — rate limits and budgets as tables per scope,
  guardrails per level as checked YAML, providers and model aliases as
  forms (a plain-text API key is never sent to the browser), and **What
  applies**: the cascade for a key, endpoint, model and end user.
- **Settings** — the gateway's facts and files, licenses, UI users,
  the audit trail, and prices: the table, your overrides, and the models
  answered without a price, priced in one step.
- **Config file editor** — `promptgate.yaml` with highlighting, a diff
  before saving, conflicts refused, the last 20 versions kept in
  `.promptgate-backups/`.
- **Per-day totals** in the request log (schema v12): per provider,
  model, key, endpoint and endpoint version, filled from the per-minute
  stats on upgrade. Charts over months and version counts read a few
  rows per day.
- **pgfuzz gate for the UI** — 232 attacks on every build: pages and
  actions without a session or with forged cookies, forms without a
  token or from another site, password guessing, name enumeration,
  session fixation, open redirects, cookie flags, security headers,
  path traversal and reflected markup — all must fail.
- The Docker image serves the UI on port 7879.

### Changed

- `promptgate endpoints history` counts each version's requests from the
  per-day totals: as far back as `logging.stats_retention`, without
  scanning the log.
- `promptgate licenses` also lists the embedded fonts (SIL Open Font
  License).
- A reload asked for by the web UI is not repeated when the file watcher
  then notices the same change.

### Fixed

- Answers served from an endpoint's answer cache counted as requests
  without a price ("unpriced") instead of costing $0.

### Performance

Measured against v0.5.0 under the same load
(bench/results/2026-10-21-go-v0.6.0-release.md):

- The proxy path is as fast as in v0.5.0 with the UI on (31,000
  requests/s at 16 clients either way).
- UI pages answer in 1–3 ms with two million logged requests; the
  charts, totals and version counts don't grow with the log.
- 18.1 MB binary (7.3 MB gzip, +1.1 MB for the UI), ready in ≈ 0.1 s,
  28 MB heap after start (+3 MB).
