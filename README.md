# PromptGate Documentation

Official documentation for **PromptGate — AI Gateway Platform**.

Built with [Astro Starlight](https://starlight.astro.build/) — available at [docs.promptgate.dev](https://docs.promptgate.dev).

## Development

```bash
npm install
npm run dev
```
